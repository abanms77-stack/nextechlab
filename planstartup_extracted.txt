For Option 1, I’d build toward one concrete objective:
Create a predictive “effective context” model that tells you how much of an LLM’s 
advertised context is actually usable for a specific task, then build a runtime system 
that automatically optimizes context before the model sees it.
The opportunity is real, but the research question needs sharpening. Existing work already 
shows that nominal context length can badly overstate practical performance: Lost in the Middle 
found strong position-dependent degradation, RULER showed many models fail well before their 
advertised context size as task complexity increases, and BABILong reported that models can 
effectively use only a fraction of very long contexts on reasoning tasks. Anthropic also explicitly 
describes context as a finite resource with diminishing usefulness as prompts grow.
So your novelty cannot simply be “long contexts degrade.” That is already known.
Your target should be:
Predict the degradation curve before running the task, generalize it across 
models/tasks, then modify context/training so the predicted usable-context 
boundary moves outward.
